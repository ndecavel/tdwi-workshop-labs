## Retrieval method

The Flipsnack `full-view.html` viewer pages themselves had no embedded PDF or download URL — they only expose an `<iframe>` pointing at the Flipsnack page-image player, and every player config on `d3ms8mre5rhtvu.cloudfront.net` returned `window.downloadMode = "false"`, meaning the publisher (CalHR) explicitly disabled the "Download" button for every one of these flipbooks. No Flipsnack API/CDN download endpoint was attempted or used, per the "don't bypass a disabled download" constraint.

What worked instead (step 4 in the brief): CalHR separately publishes most of these same documents as plain PDFs on `benefits.calhr.ca.gov/wp-content/uploads/sites/362/...`, discovered via web search for each document's exact title, then confirmed with a plain `curl -I` HEAD request (HTTP 200, `content-type: application/pdf`). Filenames follow a predictable per-batch pattern (most 2026 docs landed under `.../sites/362/2025/12/<Title-Case-Name>.pdf`), which let several additional URLs be found by pattern-guessing and HEAD-checking rather than searching individually (e.g. `2026-Long-Term-Disability-Benefits-Guide.pdf`, `2026-EAP-*.pdf` flyers). `2026-Dental-Active-Handbook.pdf` 404'd; the actual file has a WordPress-deduplicated filename, `2026-Dental-Active-Handbook-1.pdf`.
